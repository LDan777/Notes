
# 第九讲：拟牛顿法及其他变体算法

## 1. 拟牛顿法（Quasi-Newton Methods）核心引论

### 1.1 核心动机与背景

在传统的**牛顿法**中，每次迭代都需要计算目标函数 $f(x)$ 的海森矩阵（Hessian Matrix） $\nabla^{2}f(x)$ 并求解一个线性方程组，其计算复杂度为 $\mathcal{O}(n^3)$ 。当变量维度 $n$ 非常大时，海森矩阵的计算与求逆将成为无法承受的瓶颈 。

**拟牛顿法的核心思想**：用一个正定矩阵 $B_k \succ 0$ 来近似海森矩阵 $\nabla^{2}f(x)$ ，或者用 $H_k \succ 0$ 来直接近似海森矩阵的逆 $\nabla^{2}f(x)^{-1}$ 。这样既保留了二阶优化方法的快速收敛特性，又将每次迭代的计算复杂度大幅降低 。

### 1.2 基本框架与下降方向

考虑目标函数 $f(x)$ 在当前迭代点 $x_k$ 处的二次泰勒近似模型 ：


$$m_k(p) = f(x_k) + \nabla f(x_k)^T p + \frac{1}{2} p^T B_k p$$



为了找到该近似模型的极小值点，我们对 $p$ 求导并令导数等于 0 ：


$$\nabla m_k(p) = \nabla f(x_k) + B_k p = 0 \implies p_k = -B_k^{-1} \nabla f(x_k)$$



从而得到下一次迭代的更新公式 ：


$$x_{k+1} = x_k + t_k p_k$$

其中 $t_k$ 为步长（可通过线搜索确定） 。因此，核心问题转化为了：**如何高效、合理地计算或更新 $B_k$ （或 $H_k$ ）？** 

---

## 2. 割线方程与曲率条件（The Secant Equation & Curvature Condition）

为了让近似矩阵 $B_{k+1}$ 能够捕捉到局部二阶几何信息，我们要求在下一个迭代点 $x_{k+1}$ 处的二次近似模型 $m_{k+1}(p)$ 的梯度，能够匹配目标函数 $f$ 在 $x_k$ 和 $x_{k+1}$ 处的真实梯度 。

### 2.1 割线方程的深度推导

在 $x_{k+1}$ 处的二次近似模型为 ：


$$m_{k+1}(p) = f(x_{k+1}) + \nabla f(x_{k+1})^T p + \frac{1}{2} p^T B_{k+1} p$$

对其求梯度得到 ：


$$\nabla m_{k+1}(p) = \nabla f(x_{k+1}) + B_{k+1} p$$

1. 当 $p = 0$ 时，模型梯度与真实梯度自然匹配 ：



$$\nabla m_{k+1}(0) = \nabla f(x_{k+1})$$





2. 当从 $x_{k+1}$ 回退到 $x_k$ 时，位移量为 $x_k - x_{k+1} = -t_k p_k$ 。我们要求此时的模型梯度等于 $x_k$ 处的真实梯度 ：



$$\nabla m_{k+1}(-t_k p_k) = \nabla f(x_{k+1}) - t_k B_{k+1} p_k = \nabla f(x_k)$$






为了简化表述，定义**位移变化量 $s_k$** 与 **梯度变化量 $y_k$** ：


$$s_k = x_{k+1} - x_k = t_k p_k$$



$$y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$$



带入上式移项整理，即可得到著名的**割线方程（Secant Equation）** ：


$$B_{k+1} s_k = y_k$$

同理，若使用 $H_{k+1}$ 近似海森矩阵的逆，则割线方程表现为 ：


$$s_k = H_{k+1} y_k$$



### 2.2 曲率条件（Curvature Condition）

为了保证优化算法的稳定性和下降性质，近似矩阵 $B_{k+1}$ 必须满足**正定性**（ $B_{k+1} \succ 0$ ） 。
在割线方程 $B_{k+1} s_k = y_k$ 两边同时左乘 $s_k^T$ ，根据正定矩阵的性质（对于任意非零向量 $s_k$ ，恒有 $s_k^T B_{k+1} s_k > 0$ ），我们可以推导出**曲率条件** ：


$$s_k^T y_k > 0$$

## 3. 步长选择：Wolfe 条件与曲率条件的维持

在实际算法中，为了确保每次迭代都能实现充分下降，并且能自适应满足拟牛顿法所需的曲率条件 $s_k^T y_k > 0$ ，我们通常使用 **Wolfe 条件**来进行线搜索 。

### 3.1 Wolfe 条件的数学形式

对于一个给定的下降方向 $p_k$ ，步长 $t_k$ 必须同时满足以下两个不等式 ：

1. 
**充分下降条件（Armijo 条件）** ：



$$f(x_k + t_k p_k) \le f(x_k) + c_1 t_k \nabla f(x_k)^T p_k$$





2. 
**曲率条件** ：



$$\nabla f(x_k + t_k p_k)^T p_k \ge c_2 \nabla f(x_k)^T p_k$$


其中参数范围限制为： $0 < c_1 < c_2 < 1$ 。



### 3.2 逻辑因果：为什么 Wolfe 条件能保证曲率条件？

**【深度推导证明】**：
已知 $s_k = t_k p_k$ 且 $p_k$ 是一个下降方向（即 $\nabla f(x_k)^T p_k < 0$ ） 。
我们将包含梯度的第二个 Wolfe 不等式  两边同时减去 $\nabla f(x_k)^T p_k$：


$$\nabla f(x_k + t_k p_k)^T p_k - \nabla f(x_k)^T p_k \ge c_2 \nabla f(x_k)^T p_k - \nabla f(x_k)^T p_k$$

$$(\nabla f(x_k + t_k p_k) - \nabla f(x_k))^T p_k \ge (c_2 - 1) \nabla f(x_k)^T p_k$$



将 $y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$ 代入上式左侧，并将等式两边同乘步长 $t_k > 0$ ：


$$y_k^T (t_k p_k) \ge (c_2 - 1) t_k \nabla f(x_k)^T p_k$$

由于 $s_k = t_k p_k$ ，上式即为：


$$y_k^T s_k \ge (c_2 - 1) t_k \nabla f(x_k)^T p_k$$



因为 $c_2 < 1 \implies (c_2 - 1) < 0$ ，且 $p_k$ 是下降方向导致 $\nabla f(x_k)^T p_k < 0$ ，两个负数相乘为正，故有 ：


$$(c_2 - 1) t_k \nabla f(x_k)^T p_k > 0 \implies y_k^T s_k > 0$$

**结论**：只要步长 $t_k$ 满足 Wolfe 条件，拟牛顿法所需的曲率条件 $s_k^T y_k > 0$ 就一定能自动得到满足 。

## 4. DFP 与 BFGS 矩阵更新公式深度解析

为了保证每一步更新的 $B_{k+1}$ 或 $H_{k+1}$ 尽可能紧邻前一步的值（保证算法稳定性），同时满足割线方程，我们通过加权弗罗贝尼乌斯范数（Weighted Frobenius Norm）最小化问题来推导更新公式 。

### 4.1 DFP 更新公式（Davidon-Fletcher-Powell）

DFP 算法选择在海森矩阵 $B$ 的层面上进行变分约束 ：


$$\min_{B} \|B - B_k\|_{F,W}$$



$$\text{s.t. [cite_start]} B = B^T, \quad B s_k = y_k$$

通过引入拉格朗日乘子法求解该矩阵优化问题，可得到 **$B_{k+1}$ 的 DFP 更新公式** ：


$$B_{k+1} = (I - \rho_k y_k s_k^T) B_k (I - \rho_k s_k y_k^T) + \rho_k y_k y_k^T$$

其中 $\rho_k = \frac{1}{y_k^T s_k}$ 。

为了避免在计算下降方向时对 $B_k$ 进行 $\mathcal{O}(n^3)$ 的求逆运算 ，我们利用 **Sherman-Morrison-Woodbury 公式**（见本节附录）对上式直接求逆 ，得到 **$H_{k+1} = B_{k+1}^{-1}$ 的直接更新公式** ：


$$H_{k+1} = H_k - \frac{H_k y_k y_k^T H_k}{y_k^T H_k y_k} + \frac{s_k s_k^T}{y_k^T s_k}$$



### 4.2 BFGS 更新公式（拟牛顿法的黄金标准）

由于 DFP 算法对海森矩阵的逆的近似容易受到数值不稳定性的影响，后来被 **BFGS 算法**所取代 。BFGS 采取了“对偶”的思想，直接在海森矩阵的逆 $H$ 的层面上求解最小化问题 ：


$$\min_{H} \|H - H_k\|_{F,W}$$



$$\text{s.t. [cite_start]} H = H^T, \quad s_k = H y_k$$

求解该对偶优化问题，直接得到 **$H_{k+1}$ 的 BFGS 更新公式** ：


$$H_{k+1} = (I - \rho_k s_k y_k^T) H_k (I - \rho_k y_k s_k^T) + \rho_k s_k s_k^T$$

其中 $\rho_k = \frac{1}{y_k^T s_k}$ 。

对上式应用 Sherman-Morrison-Woodbury 公式求逆，可得其对应的**海森矩阵 $B_{k+1}$ 的更新公式** ：


$$B_{k+1} = B_k - \frac{B_k s_k s_k^T B_k}{s_k^T B_k s_k} + \frac{y_k y_k^T}{y_k^T s_k}$$



### 附：Sherman-Morrison-Woodbury (SMW) 公式

当我们在一个已知逆的矩阵上添加一个低秩修正时，SMW 公式可以极其高效地计算修改后矩阵的逆 ：


$$(A + U C V^T)^{-1} = A^{-1} - A^{-1} U (C^{-1} + V^T A^{-1} U)^{-1} V^T A^{-1}$$

该公式正是 DFP 与 BFGS 算法能够在 $B_k$ 和 $H_k$ 之间自由切换、且维持 $\mathcal{O}(n^2)$ 极低计算复杂度的数学基石 。

## 5. 统一的拟牛顿标准算法流程（Algorithm 1）

```
输入: 初始点 x_0, 线搜索参数 α ∈ (0, 1/2), β ∈ (0, 1), 收敛精度 ε
1: 初始化 H_0 (例如 H_0 = I 或结合第一步计算进行缩放) 
2: for k = 0, 1, 2, ... do
3:     计算下降方向: d_k = -H_k ∇f(x_k)  (或者通过解 B_k d_k = -∇f(x_k) 得到)
4:     利用 Wolfe 条件进行线搜索选择步长 t_k (优先尝试 t_k = 1)
5:     更新迭代点: x_{k+1} = x_k + t_k d_k
6:     计算位移差与梯度差: s_k = x_{k+1} - x_k,  y_k = ∇f(x_{k+1}) - ∇f(x_k)
7:     if ||∇f(x_{k+1})|| <= ε then
8:         停止算法，输出当前最优解 x_{k+1}
9:     end if
10:    根据 DFP 或 BFGS 公式更新 B_{k+1} 或 H_{k+1}
11: end for

```

(注：讲义第5页代码有部分行号错位，此处已根据标准逻辑梳理纠正 )

### 5.1 性能对比与收敛性分析

* 
**计算复杂度对比** ：


* 
**传统牛顿法**：每步迭代需要 $\mathcal{O}(n^3)$ 计算量，且需要计算真实的海森矩阵 。


* 
**BFGS 拟牛顿法**：由于直接维护 $H_k$ ，每步迭代仅需矩阵-向量乘法，计算量为 $\mathcal{O}(n^2)$ 。




* 
**收敛速度定理（Convergence of BFGS）** ：
如果目标函数 $f$ 二次连续可微，且强凸（存在正常数 $m, M$ 使得 $m\|z\|^2 \le z^T \nabla^2 f(x) z \le M\|z\|^2$ ） ，那么采用 Wolfe 线搜索的 BFGS 序列 $\{x_k\}$ 会收敛到全局极小值点 $x^*$ 。如果海森矩阵局部 Lipschitz 连续，其收敛速率可达到**超线性收敛（Superlinear rate）** ：



$$\|x_{k+1} - x^*\| [cite_start]\le o(\|x_k - x^*\|)$$

## 6. 大规模优化延伸：L-BFGS 与紧凑表示

### 6.1 L-BFGS（Limited-memory BFGS）

**痛点**：虽然 BFGS 将计算量降到了 $\mathcal{O}(n^2)$ ，但对于超高维问题（如千万级参数的机器学习模型），存储一个 $n \times n$ 的稠密矩阵 $H_k$ 需要 $\mathcal{O}(n^2)$ 的内存空间，这依然是不现实的 。

**L-BFGS 的核心解决方案**：不显式存储 $H_k$ 矩阵 。因为 $H_k$ 是由初始矩阵 $H_0$ 经过一系列历史向量对 $(s_j, y_j)$ 纠缠修正得到的 ，因此我们只需要在内存中维护一个大小为 $m$ （通常 $m \in [5, 15]$ ）的**最近历史滑动窗口**，保存最近 $m$ 步的 $s_j$ 和 $y_j$ 向量即可 。

通过著名的 **L-BFGS 双循环递归算法（Two-loop recursion）** ，我们可以在不组装矩阵的情况下，仅通过简单的向量内积，在 **$\mathcal{O}(mn)$ 的时间复杂度**和 **$\mathcal{O}(mn)$ 的空间复杂度**下直接计算出下降方向 $H_k \nabla f(x_k)$ ：

```
算法 2: L-BFGS 双循环递归
输入: 当前梯度 q = ∇f(x_k), 最近 m 步的历史控制点对 (s_j, y_j)
1: q ← ∇f(x_k)
2: for j = k - 1, k - 2, ... , k - m do
3:     α_j ← ρ_j * (s_j^T * q)
4:     q ← q - α_j * y_j
5: end for
[cite_start]6: r ← H_0^k * q   (通常 H_0^k 取对角阵, 如 [cite:116] 的缩放矩阵)
7: for j = k - m, k - m + 1, ... , k - 1 do
8:     β ← ρ_j * (y_j^T * r)
9:     r ← r + s_j * (α_j - β)
10: end for
11: return r  (所得的 r 即为 H_k ∇f(x_k))

```

(注：第18页原文第6行 $H_k^0$ 实际在循环中可针对当前步进行自适应标量缩放 )

### 6.2 BFGS 矩阵更新的紧凑表示（Compact Representation）

BFGS 的更新还可以写成一整个大矩阵相乘的形式，这对于并行计算或分布式理论分析非常有用 。令初始矩阵为 $H_0 \in \mathbb{S}_{++}^n$ ，将前 $k$ 步的所有历史向量拼接成矩阵 $S_k, Y_k \in \mathbb{R}^{n \times k}$ ：


$$S_k = [s_0, s_1, \dots, s_{k-1}], \quad Y_k = [y_0, y_1, \dots, y_{k-1}]$$

则 $H_k$ 能够被精确紧凑地表示为 ：


$$H_k = H_0 + (S_k \quad H_0 Y_k) \begin{pmatrix} W_k & -R_k^{-T} \\ -R_k^{-1} & 0 \end{pmatrix} \begin{pmatrix} S_k^T \\ Y_k^T H_0 \end{pmatrix}$$

其中 $R_k$ 为 $k \times k$ 的上三角矩阵，其非零元为 $(R_k)_{ij} = s_{i-1}^T y_{j-1} \, (i \le j)$ ；$D_k$ 为对角阵 $Diag(s_0^T y_0, \dots, s_{k-1}^T y_{k-1})$ ；并且 $W_k = R_k^{-T}(D_k + Y_k^T H_0 Y_k)R_k^{-1}$ 。

## 7. 补充一阶方法：Barzilai-Borwein (BB) 梯度法

BB 方法是一种极其特殊的“借用拟牛顿法思想”的**一阶梯度方法** 。

### 7.1 BB 步长的一阶拟牛顿推导

普通梯度下降法的更新为 $x_{k+1} = x_k - t_k \nabla f(x_k)$ 。BB 方法提出：我们能否选择一个**纯标量步长 $t_k$**，使得标量矩阵 $D_k = t_k I$ 能够最大程度地模拟拟牛顿法的逆割线方程 $H_k y_{k-1} = s_{k-1}$ 呢？ 由于标量矩阵无法完全满足矩阵方程，我们退而求其次，通过求解最小二乘问题来逼近 ：

* 
**视角一**：最小化位移近似误差 


$$\min_{t_k} \|s_{k-1} - t_k I y_{k-1}\|^2$$


对 $t_k$ 求导并令其为 0，可以轻松解得 **BB 第一步长更新公式** ：



$$t_k = \frac{s_{k-1}^T y_{k-1}}{y_{k-1}^T y_{k-1}}$$





* 
**视角二（对称视角）**：最小化逆向割线误差 


$$\min_{t_k} \|t_k^{-1} I s_{k-1} - y_{k-1}\|^2$$


同理求导解得 **BB 第二步长更新公式** ：



$$t_k = \frac{s_{k-1}^T s_{k-1}}{s_{k-1}^T y_{k-1}}$$






### 7.2 实际技巧：非单调线搜索（Non-monotone Line Search）

在实际运算中，BB 步长经常会产生极其激进的巨大步长，导致目标函数值剧烈震荡 。因此需要对其进行截断约束（限制在 $[t_{\min}, t_{\max}]$ 之间），并搭配**非单调线搜索**（即不要求每一步都严格下降，而是只要比过去几步的*最大值*小即可） ：


$$f(x_k + t_s p_k) \le \max_{i=k-m, \dots, k-1} f(x_i) + \alpha t_s p_k^T \nabla f(x_k)$$

## 8. 非线搜索体系：信赖域方法与立方正则化

与前面通过“先定方向、再找步长”的线搜索体系不同 ，本节介绍另外两种主流的二阶现代优化范式。

### 8.1 信赖域方法（Trust Region Method）

信赖域方法在每一步迭代时，直接限制原二次近似模型能够被“信任”的**最大半径半径 $\Delta_k$** 。其子问题形式为 ：


$$\min_{p} m_k(p) = f(x_k) + \nabla f(x_k)^T p + \frac{1}{2} p^T \nabla^2 f(x_k) p$$



$$\text{s.t. } \|p\| [cite_start]\le \Delta_k$$



#### 核心动态调整机制（基于评价因子 $\rho_k$ ）

我们通过定义**实际下降量与预测下降量的比值 $\rho_k$**，来决定是否接受这一步，以及如何缩放下一阶段的信赖域半径 ：


$$\rho_k = \frac{f(x_k) - f(x_k + p_k)}{m_k(0) - m_k(p_k)}$$



* 
**$\rho_k < \frac{1}{4}$ （模型极其不准）**：说明当前信赖域定得太大了，二阶近似严重失真。我们拒绝或者谨慎对待这一步，并将半径缩小 ： $\Delta_{k+1} = \frac{1}{4}\Delta_k$ 。


* **$\rho_k > \frac{3}{4}$ 且 $\|p_k\| [cite_start]= \Delta_k$ （模型非常完美且触碰边界）**：说明当前模型极度可信，我们可以大胆地将信赖域半径扩大一倍 ： $\Delta_{k+1} = \min(2\Delta_k, \hat{\Delta})$ 。


* 
**其他情况**：维持半径不变 ： $\Delta_{k+1} = \Delta_k$ 。


* 
**更新判定**：只要 $\rho_k \ge \eta$ （ $\eta$ 是一个极小的正数），就接受该步并更新 $x_{k+1} = x_k + p_k$；否则原地踏步 。



### 8.2 三次正则化牛顿法（Cubically Regularized Newton's Method）

传统的梯度下降或牛顿法，本质上是在局部增加一个二次的惩罚项（例如等价形式： $x_{k+1} = \arg\min_x f(x_k) + \nabla f(x_k)^T(x-x_k) + \frac{1}{2t_k}\|x-x_k\|^2$ ） 。

为了彻底突破传统二阶优化在非凸长峡谷地形中容易陷入鞍点的困境，三次正则化选择在模型中直接加入**三次高阶惩罚项** ：


$$x_{k+1} = \arg\min_{x} f(x_k) + \nabla f(x_k)^T(x-x_k) + \frac{1}{2}(x-x_k)^T \nabla^2 f(x_k) (x-x_k) + \frac{L}{6}\|x-x_k\|^3$$

当 $L$ 为海森矩阵 $\nabla^2 f(x)$ 的 Lipschitz 常数时，该三次近似模型在数学上构成了目标函数 $f(x)$ 的一个全局上界（Upper Bound） 。

* **收敛速率优势**：
* 在一般的**非凸问题**中，它能保证 $\mathcal{O}(\epsilon^{-3/2})$ 的全局收敛速率，并且在极值点附近享有二次收敛速率 。


* 在一般的**凸问题**中，它享有 $\mathcal{O}(\epsilon^{-1/3})$ 的全局收敛速率 。

## 9. 最小二乘专用：高斯-牛顿法与 LM 算法

针对工业界最常见的**非线性最小二乘问题** ： $\min_{x} \frac{1}{2}\|g(x)\|^2 = \frac{1}{2}\sum_{i=1}^m [g_i(x)]^2$ 。

### 9.1 高斯-牛顿法（Gauss-Newton Method）的推导与剥离

在每一次迭代中，我们对非线性向量函数 $g(x)$ 进行局部线性化（一阶泰勒展开） ：


$$g(x) \approx g(x_k) + J_k (x - x_k)$$

其中 $J_k = J_g(x_k) \in \mathbb{R}^{m \times n}$ 是 $g$ 在 $x_k$ 处的雅可比矩阵（Jacobian） 。我们将这个线性近似带入最小二乘目标函数中 ：


$$x_{k+1} = \arg\min_{x} \frac{1}{2} \|g(x_k) + J_k (x - x_k)\|^2$$



对该二次极小化问题求导并令其为 0：


$$J_k^T \left( g(x_k) + J_k (x - x_k) \right) = 0 \implies J_k^T J_k (x - x_k) = -J_k^T g(x_k)$$

若假设 $J_k$ 是满列秩的，则 $(J_k^T J_k)$ 正定可逆 ，直接解得**高斯-牛顿更新公式** ：


$$x_{k+1} = x_k - t_k (J_k^T J_k)^{-1} J_k^T g(x_k)$$



### 9.2 关键对比：高斯-牛顿法与标准牛顿法的因果纽带

我们来看该优化目标真实的完整海森矩阵公式 ：


$$\nabla^2 \left( \frac{1}{2}\|g(x)\|^2 \right) = J_g(x)^T J_g(x) + \sum_{i=1}^m g_i(x) \nabla^2 g_i(x)$$


**因果与代价分析**：
高斯-牛顿法本质上是**直接无情地丢弃了海森矩阵的第二项 $\sum_{i=1}^m g_i(x) \nabla^2 g_i(x)$** 。

* 
**好处**：极大地节省了计算量。我们完全不需要去计算每一个子函数 $g_i(x)$ 的二阶海森矩阵 $\nabla^2 g_i(x)$ 。


* 
**代价与适用场景**：这一近似导致了收敛速率的某种退化 。显然，只有当第二项很小（即残差 $g_i(x)$ 接近于 0，也就是模型拟合得非常好，或者问题本身是求非线性方程组根 $g(x)=0$ 时），高斯-牛顿法的近似效果才会非常优异 。



### 9.3 雅可比不满秩的救星：Levenberg-Marquardt (LM) 方法

当雅可比矩阵 $J_k$ 不满列秩时，矩阵 $(J_k^T J_k)$ 将会变成奇异矩阵或病态矩阵，导致求逆崩溃 。
LM 算法通过引入一个**阻尼岭回归系数 $\mu_k I$** 彻底解决了这一固有缺陷 ：


$$x_{k+1} = x_k - t_k (J_k^T J_k + \mu_k I)^{-1} J_k^T g(x_k)$$

这一巧妙的修正不仅保证了括号内矩阵的绝对正定可逆，还在形式上完美融合了“梯度下降法”（当 $\mu_k$ 很大时）与“高斯-牛顿法”（当 $\mu_k$ 趋近于 0 时）的各自双重优势 。
